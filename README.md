# Crimson Workstation

Zee's two-book fantasy project. **Locked order: finish Crimson Dynasty (prequel) FIRST, then continue Crimson Legacy.** Without Dynasty, there is no Legacy.

## Layout

- `dynasty/` — **Crimson Dynasty** (the prequel — Zee Darkheart's story)
  - `canon.md` — locked canon: Zee's story, houses, timeline, rules
  - `chapters.md` — chapter map (threads run through Ch 146)
  - `characters.md` — character sheets
- `legacy/` — **Crimson Legacy** (Aidan Darkheart's story — 3 arcs: Witch, Vampire, Wolf)
  - `chapter_map.md` — master chapter map: what's written, gaps, conflicts, next steps
  - `canon.md` — locked canon: the System vs the Legacy, arc rules, authorities
  - `characters.md` — character sheets
- `shared/` — canon shared across both books (world bible, hybrid classes, bloodlines)

## Key locked decisions (Zee)

- Dynasty first — Legacy stays paused until Dynasty is done (Oct 8, 2026).
- Legacy's 3 parts = the Witch Arc, the Vampire Arc, the Wolf Arc.
- Witch Arc ends at Ch 101 ("Two Years Later"); Vampire Arc starts after 101.
- Zee has 3 sons, Aidan Seyrion Darkheart the oldest; then Zayrlen Keal and Azren Neyron Darkheart (with Ner Azrion).
- Aidan's mother: Queen Nymeris Thalryn. Cassian is NOT Aidan's parent.
- QuinZ, Zuko, Azula are Aidan & Lyra's children — later in Aidan's life, Zee won't be around for it.
- The System informs/records/delivers; the Legacy judges/decides. Rule #1: only Aidan can see/hear the System.
- Cassian = permanent antagonist (Phase 3 kills Lyra). Lyra = future First Crimson Queen.
- Wolf Arc is canon-gated: nothing written until Lyra's death (Decrees 44, 48, 49).
